# Brand gallery

Reference login pages used by the gateway's vision check. When an escalation carries a consented
screenshot, the gateway embeds it with MobileNetV3-Small and compares it with every image here
(cosine similarity). A close match on a domain that does not belong to that brand is flagged.

- One folder per brand, named in lowercase without spaces: `google`, `microsoft`, `apple`, `paypal`,
  `amazon`, `bankofamerica`. The folder name is the brand key used by the gateway.
- Supported files: `.png`, `.jpg`, `.jpeg`, `.webp`.
- `_generic/` holds non-brand login cards used as a negative class: a screenshot is only flagged when it
  is closer to a brand than to these generic cards. Add real generic login pages here to reduce false positives.
- `synthetic_*.png` are generated by `apps/backend/scripts/build_brand_gallery.py` from brand colours and
  wordmark text only (no logo files). Re-run the script to regenerate them.
- Operators can drop official screenshots of real login pages into the same folders to extend the
  gallery. Whether you may use a given brand's imagery is the operator's call; the repository ships no
  trademarked artwork.
- Screenshots sent by users are never written here, stored or logged.
